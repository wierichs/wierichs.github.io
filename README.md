# PWA Playground

This repository brings together my experiments with Progressive Web Apps
(PWAs): websites that can also be installed and used like apps.

## First Steps

[FirstTry](FirstTry/) and [GeoLocator](GeoLocator/) were my first steps toward
building a PWA. These projects helped me explore the basics and gain practical
experience.

- [Try FirstTry](https://wierichs.github.io/FirstTry/)
- [Try GeoLocator](https://wierichs.github.io/GeoLocator/)

## Jagdkarte

Together with **GitHub Copilot**, I developed **Jagdkarte**, a PWA focused on
real-world use cases for hunters. It brings together hunting-district maps,
shared revier profiles, markers, and optional location sharing within a group.

- **[Open Jagdkarte](https://wierichs.github.io/Jagdkarte/)**
- [Technical documentation and setup](Jagdkarte/README.md)
- [German user guide](https://wierichs.github.io/Jagdkarte/hilfe.html), also
  accessible through the question-mark icon in the app
- [User guide source](Jagdkarte/hilfe.html)
